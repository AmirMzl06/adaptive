# Self-Supervised Neural Population Representation Learning
## Experimental Report: Cross-Population Gaussian Mutual Information and Nested Subpopulation Ranking

**Dataset:** Perich monkey motor-cortex recordings  
**Evaluation:** Frozen neural embeddings followed by supervised Ridge regression for behavioral decoding  
**Experiments:** 17 completed training runs across two configurations  
**Hardware:** One NVIDIA H200 GPU per job  
**Random seed:** 0

---

## 1. Research Objective

The goal is to learn representations of neural population activity without using behavioral labels during pretraining, without reconstructing spike activity, and without predicting future spikes.

The central hypothesis is that a useful neural representation should preserve information shared between different neuronal subpopulations.

For each training batch, the neural population is divided into two disjoint groups:

- **A:** Input neuronal population.
- **B:** Reference neuronal population used to define the self-supervised objective.

An encoder receives spike-count windows from a subset of A and produces a low-dimensional representation.

We maximize a Gaussian mutual-information estimate between that representation and the simultaneously recorded activity of B.

We also investigated an auxiliary ranking constraint based on the expected increase in information when more neurons from A are included.

Behavioral labels are used only to train and evaluate downstream probes; they are not used to update the encoder during self-supervised pretraining.

## 2. Shared Neural Encoder Architecture

All self-supervised conditions use the same neural network. The ablations modify the input construction and/or training objective, not the encoder architecture.

**Input**

- Spike-count windows spanning 36 time bins.
- A variable number of input neurons.
- Separate learned identity embeddings for each neuron.

**Architecture**

1. A shared per-neuron temporal CNN with three Conv1D layers, GELU activations, and a linear projection.
2. A learned neuron-ID embedding added to each temporal token.
3. Two Transformer encoder layers with four attention heads per layer, operating across neuronal tokens.
4. Attention pooling using four learned query vectors.
5. A final linear projection producing a **32-dimensional representation**.

**Architectural hyperparameters**

| Parameter | Value |
|---|---|
| Temporal window | 36 bins |
| Token dimension | 64 |
| Transformer layers | 2 |
| Attention heads | 4 |
| Learned pooling queries | 4 |
| Output embedding dimension | 32 |
| Dropout | 0 |
| Input spike smoothing | 0 |
| Reference population smoothing | Gaussian sigma = 2 bins |

The model can process variable-sized neuronal sets because the Transformer and learned-query pooling are applied across the available neuron tokens.

## 3. Self-Supervised Training Objective

For nested subpopulations:

`A_k1 ⊂ A_k2 ⊂ A_k3 ⊂ A_k4`

the encoder produces:

`z_k = f_theta(X_Ak)`

For each representation, a Gaussian mutual-information proxy is computed with the activity of reference population B:

`M_k = I_G(z_k ; X_B)`

The estimate is based on regularized covariance matrices and Gaussian log-determinants:

`I_G(z; B) = 0.5 [logdet(C_z) + logdet(C_B) - logdet(C_joint)]`

The covariance regularization parameter is `mi_eps = 0.01`.

**Main information objective**

`L_MI = -(M_k1 + M_k2 + M_k3 + M_k4) / 4`

**Auxiliary ranking objective**

`L_rank = mean_{i<j} max(0, M_kj - M_ki + margin)`

where the levels are ordered from the largest to the smallest neuronal subset.

The intended ordering is:

`M_large > M_medium > M_small > M_smallest`

with `margin = 0.05`.

**Total loss**

`L_total = L_MI + lambda_rank * L_rank`

The default ranking weight is `lambda_rank = 1.0`.

The Gaussian MI values are batch-based statistical estimates rather than ground-truth mutual information. Their absolute magnitudes should not be directly compared across different batch sizes.

## 4. Experimental Conditions

| Condition | Input construction | Training objective |
|---|---|---|
| **Main** | Time-decoy replacement | MI over all levels + correct ranking |
| **No Rank** | Time-decoy replacement | MI over all levels; ranking weight = 0 |
| **Shuffled Rank** | Time-decoy replacement | MI over all levels + randomly permuted ranking order |
| **MI Full** | Time-decoy replacement | MI only at the largest level + correct ranking |
| **Decoy Zero** | Missing-neuron activity replaced with zero | MI over all levels + correct ranking |
| **Decoy Drop** | Missing neurons completely removed | MI over all levels + correct ranking |
| **Fixed B** | Time-decoy replacement with one fixed reference population | MI over all levels + correct ranking |
| **Raw Ridge** | Smoothed neural activity directly supplied to Ridge regression | Fully supervised linear baseline; no encoder pretraining |

### What is a time decoy?

In the Main condition, the number of input neuron tokens stays constant. When only some neurons are designated as the genuine subset, the remaining neurons are represented by their activity at other, temporally distant time points.

The minimum decoy offset is 360 bins.

### What is Decoy Drop?

In Decoy Drop, unselected neurons are removed completely rather than replaced. Therefore, the encoder receives actual subsets of different sizes.

For example, with 57 candidate input neurons, the four views contain 57, 28, 14, and 7 real neurons.

The same neural encoder processes all four views.

### Important implementation detail

In the current implementation, the neuronal subset can differ across individual time samples within a batch. Thus, the nested-subpopulation training protocol is not identical to a statistical analysis based on fixed neuronal subsets observed across all time points.

### Raw Ridge baseline

The Raw Ridge baseline uses Gaussian-smoothed neural activity at each time point and directly predicts six behavioral dimensions.

Unlike the self-supervised encoder, the current Raw Ridge baseline does not receive an explicit 36-bin feature window. Consequently, a Ridge baseline with the same temporal context remains necessary for a fully matched comparison.

# 8. Detailed Observations About the Ranking Objective

The most consistent finding is that the correct nested-subpopulation ordering emerges almost automatically.

In the 5,000-step experiment, Main, No Rank, and Decoy Drop showed zero ranking loss from the first recorded logging interval.

In the 2,500-step pilot:

- C-CO12 / Main: mean ranking loss approximately 0.00094 over the first 100 steps, approximately 0.00006 over the next 100 steps, and zero from around Step 300 onward.
- C-CO12 / No Rank: the same ordering emerged without any ranking optimization.
- C-CO12 / Decoy Drop: ranking loss had already become zero by Step 200.
- C-RT2: small ranking violations occasionally remained, but their contribution was substantially smaller than the information objective.

This indicates that ranking subpopulations by their size is a relatively easy task and may contribute little additional learning signal.

Shuffled Rank behaved differently. Its ranking loss remained active because the imposed ordering conflicted with the natural information ordering.

Interestingly, it underperformed badly in the short pilot but achieved the highest final R² on C-CO12 in the long run.

Because the two runs differed in both batch size and training length, this cannot yet be interpreted as evidence that shuffled ranking is beneficial regularization.

There is also a random-number-generation confound in the current shuffled-ranking implementation: drawing the random ranking order can alter the subsequent sampling sequence. Therefore, matched random streams are needed for a rigorous causal comparison.

# 9. Comparison Between the Two Training Configurations

For C-CO12:

| Condition | 2,500 steps / Batch 256 | 5,000 steps / Batch 1,024 |
|---|---:|---:|
| Main | 0.6667 | 0.6975 |
| No Rank | 0.6750 | 0.6915 |
| Shuffled Rank | 0.6078 | 0.7085 |
| Decoy Drop | 0.6895 | 0.7040 |

All four methods had higher final R² in the longer, larger-batch run.

However, the effect was particularly pronounced for Shuffled Rank.

The batch-size change also affects the finite-sample covariance estimate underlying Gaussian MI. Consequently, the MI values obtained with batches of 256 and 1,024 cannot be interpreted as directly comparable measurements of population information.

A controlled batch-size ablation is necessary to separate the effects of batch size, training length, and ranking.

# 11. Interpretation and Limitations

### 11.1 Positive results

The cross-population Gaussian MI objective learned representations that substantially outperformed random initialization on most tested sessions.

On C-CO12, trained representations also outperformed the current single-time-point Raw Ridge baseline.

Decoy Drop was consistently competitive and achieved the highest R² among the four conditions in the short pilot.

The improvement with Decoy Drop suggests that providing genuine neuronal subsets rather than temporally mismatched replacement activity may be a better training strategy.

### 11.2 The current ranking objective does not show a consistent benefit

The correct-ranking loss was typically zero or extremely small early in training, even in the absence of ranking optimization.

Main and No Rank also produced very similar behavioral decoding results.

Therefore, these experiments do not establish an independent benefit from ranking neuronal subsets by size.

### 11.3 Cross-population information is not always behaviorally relevant

C-RT2 is an important negative result.

Although the representations learned substantial statistical dependence with the reference neuronal population, behavioral decoding remained inferior to Raw Ridge.

This suggests that the shared information captured between neuronal subpopulations may contain behavior-irrelevant structure.

### 11.4 Current limitations

1. Only one random seed has been tested in the reported runs.
2. The 2,500-step and 5,000-step experiments differ in both batch size and training duration.
3. The self-supervised encoder uses a 36-bin temporal window, while the Raw Ridge baseline does not explicitly use an equivalent window.
4. The batch-based Gaussian MI estimator may exhibit finite-sample bias, especially with high-dimensional representations and small batches.
5. A shuffled-reference or temporally permuted reference-population MI null control has not yet been evaluated.
6. The Fixed B ablation has a different evaluation input from the dynamic-B conditions.
7. The current subpopulation membership varies between individual time samples within a training batch.
8. Some self-supervised objectives continue improving after behavioral decoding performance has peaked.
9. The `drop_no_rank` condition has not yet been executed, so the effect of dropping decoys has not been fully separated from the effect of the ranking term.
10. The reported validation results should be treated as exploratory rather than as estimates of generalization across animals, sessions, and seeds.

# 12. Proposed Next Experiments

The immediate next experiment should complete a controlled two-by-two ablation:

| Input construction | MI only | MI + correct ranking |
|---|---|---|
| Time-Decoy | No Rank | Main |
| Real neuronal subsets | **Drop No Rank — not yet tested** | Decoy Drop |

This would isolate the effect of the real-subpopulation input strategy from the effect of ranking.

Additional priorities are:

- Run multiple random seeds on several representative sessions.
- Add a temporally shuffled reference-population null for Gaussian MI.
- Add a temporally matched linear Ridge baseline using the full 36-bin input window.
- Separate batch-size effects from training-duration effects.
- Use identical data-sampling random streams across experimental conditions.
- Test fixed neuronal subset membership across time when estimating MI.
- Investigate whether information quality between same-sized neuronal subsets offers a more informative self-supervised ranking signal than simply changing the number of observed neurons.

## Overall Conclusion

The strongest current evidence supports the usefulness of **cross-population self-supervised representation learning**, particularly when the input is constructed from genuine neuronal subsets.

However, the additional nested-ranking constraint based purely on subset size has not demonstrated a reliable independent advantage.

The results motivate retaining the cross-population information-learning framework while investigating more informative objectives that distinguish behaviorally relevant shared structure from other forms of neuronal dependence.

These findings are preliminary and require matched temporal baselines, additional seeds, and further session-level evaluation before drawing broad conclusions.
